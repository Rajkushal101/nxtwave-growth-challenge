# Database Schema & Entity Relationships

This document defines the relational database schema implemented in SQLite (`growth_challenge.db`) for the NxtWave AI Project Matcher and Growth Engine.

---

## 1. Entity-Relationship Overview

```text
┌──────────────────────┐         1:N         ┌───────────────────────────────┐
│        users         │────────────────────<│     project_recommendations   │
│  (Quiz respondents)  │                     │  (Matched or synthesized)     │
└──────────┬───────────┘                     └───────────────────────────────┘
           │
           │ 1:1
           ▼
┌──────────────────────┐         1:N         ┌───────────────────────────────┐
│    registrations     │────────────────────<│           referrals           │
│ (Workshop attendees) │                     │ (Attributed peer conversions) │
└──────────┬───────────┘                     └───────────────────────────────┘
           │
           │ 1:N
           ▼
┌──────────────────────┐
│   analytics_events   │
│ (Funnel & telemetry) │
└──────────────────────┘
```

---

## 2. Table Definitions

### 1. `campaign_sources`
Tracks official acquisition channels and associated UTM parameters.
```sql
CREATE TABLE campaign_sources (
    id TEXT PRIMARY KEY,               -- e.g. 'src_wa_cs_club'
    source_name TEXT NOT NULL,         -- Friendly name: 'WhatsApp CSE Dept 2025'
    channel_type TEXT NOT NULL,        -- 'whatsapp', 'tech_club', 'creator', 'campus_qr'
    utm_source TEXT NOT NULL,          -- e.g. 'wa_cs'
    utm_medium TEXT NOT NULL,          -- e.g. 'social_community'
    utm_campaign TEXT NOT NULL,        -- e.g. 'build_ai_60m'
    target_registrations INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_campaign_sources_utm ON campaign_sources(utm_source, utm_medium, utm_campaign);
```

### 2. `users`
Captures quiz responses across all engineering years.
```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,               -- UUID
    session_id TEXT NOT NULL,          -- Browser session token
    year_of_study INTEGER NOT NULL,    -- 1, 2, 3, or 4
    branch TEXT NOT NULL,              -- 'CSE', 'ECE', 'MECH', 'CIVIL', 'IT', etc.
    coding_level TEXT NOT NULL,        -- 'Beginner (No code)', 'Intermediate (Basic Python/C++)', 'Advanced'
    interest_area TEXT NOT NULL,       -- 'Web/Mobile', 'Data & Analytics', 'Cybersecurity', 'Automation/Robotics', 'Generative AI'
    primary_goal TEXT NOT NULL,        -- 'Explore AI', 'Portfolio Building', 'Placement Prep', 'Hackathon Project'
    preferred_tech TEXT,               -- 'Python', 'JavaScript', 'No-code'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_users_session ON users(session_id);
CREATE INDEX idx_users_year_branch ON users(year_of_study, branch);
```

### 3. `project_recommendations`
Stores the customized 60-minute project presented to the student.
```sql
CREATE TABLE project_recommendations (
    id TEXT PRIMARY KEY,               -- UUID
    user_id TEXT NOT NULL,
    project_title TEXT NOT NULL,       -- e.g. 'AI Resume & ATS Matcher'
    category TEXT NOT NULL,            -- 'Career Tech', 'Cybersecurity', 'Productivity'
    difficulty TEXT NOT NULL,          -- 'Beginner', 'Intermediate', 'Advanced'
    estimated_minutes INTEGER DEFAULT 60,
    tech_stack TEXT NOT NULL,          -- JSON array string: ["Python", "Gemini API", "Streamlit"]
    learning_outcomes TEXT NOT NULL,   -- JSON array of bullet points
    portfolio_relevance TEXT NOT NULL, -- Why this impresses recruiters
    is_ai_generated BOOLEAN DEFAULT 0, -- 1 if generated by LLM, 0 if deterministic fallback
    generated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_project_user ON project_recommendations(user_id);
```

### 4. `registrations`
Stores student workshop sign-ups and their unique referral identifiers.
```sql
CREATE TABLE registrations (
    id TEXT PRIMARY KEY,               -- UUID
    user_id TEXT NOT NULL UNIQUE,
    full_name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    whatsapp_number TEXT NOT NULL,
    college_name TEXT NOT NULL,
    referral_code TEXT UNIQUE NOT NULL,-- e.g. 'KARTHEEK7' (uppercase + random/hash)
    referred_by_code TEXT,             -- referral_code of the student who invited them
    registered_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_reg_referral_code ON registrations(referral_code);
CREATE INDEX idx_reg_referred_by ON registrations(referred_by_code);
CREATE INDEX idx_reg_email ON registrations(email);
```

### 5. `referrals`
Tracks student referral conversions and milestone unlocks.
```sql
CREATE TABLE referrals (
    id TEXT PRIMARY KEY,               -- UUID
    referrer_code TEXT NOT NULL,       -- Referral code of referring student
    referred_user_id TEXT NOT NULL,    -- User ID of new registrant
    status TEXT DEFAULT 'completed',   -- 'clicked', 'registered', 'verified'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (referrer_code) REFERENCES registrations(referral_code)
);

CREATE INDEX idx_referrals_referrer ON referrals(referrer_code);
```

### 6. `analytics_events`
Ingests all client telemetry for the full growth funnel.
```sql
CREATE TABLE analytics_events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    event_name TEXT NOT NULL,          -- 'page_view', 'quiz_completed', etc.
    utm_source TEXT,
    utm_medium TEXT,
    utm_campaign TEXT,
    referrer_url TEXT,
    metadata_json TEXT,                -- Flexible context (e.g. step number, project_id)
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_events_name_time ON analytics_events(event_name, timestamp);
CREATE INDEX idx_events_utm ON analytics_events(utm_source, utm_campaign);
```
